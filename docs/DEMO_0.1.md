# 《命运转盘》Demo 0.1 交付说明

> 此文记录最初 Demo。当前招募已按后续要求改为七等分转盘、每次固定 10 金币和专属转职确认，原九格与随等级涨价的招募描述已作废；以 [转盘改造说明](ROULETTE_UPDATE.md) 为准。战斗 AI、数值与五波系统保持原样。

## 开发前检查与修改范围

- 原工程为 Cocos Creator 3.8.8，1920×1080、fitHeight 横屏项目。本机有对应引擎。
- 原有 `MainMenu.scene`、`ChapterCard.prefab`、`ChapterSelectionLayout.ts`、月夜城堡分层背景、Logo、章节图、Fusion Pixel 字体、守卫八帧待机和篝火动画全部保留。
- 没有发现正式转职名称、技能数值、其他等级上阵位置、正式 20 波等设计资料，全部缺项以独立测试配置或空数据接口承接。
- 修改前已有 `profiles/v2/packages/builder.json`、`profiles/v2/packages/scene.json`、`settings/v2/packages/information.json` 的未提交修改，以及两个未跟踪编辑器配置文件。没有还原这些用户改动。Creator 打开/构建会继续更新本地编辑器缓存与配置。
- 没有执行 Git commit、push，也没有删除主界面或原有资源。

## 已完成功能

开局 100 金币、0 单位、3 个位置；招募价格 10～28 金币，九格随机结果只选一个，随后独立三选一转职。每次招募必须完成替换（如满编）、布阵确认和合成提示，才能继续招募或开战。满编可招募并选择替换已有单位，返还投入成本的测试比例。可以自由拖动准备区内的单位，战斗中阵容锁定。

三合一升二星、九个一星可连续合成三星；每次可合成或保留。强化的是原技能倍率与目标数量，三星仍按同一技能配置的固定冷却自动释放。没有换发无关技能。

全部友军和敌军独立自主行动，无主角、摇杆、移动/攻击/选目标/放技能按钮。近战接敌、远程射程内攻击与短时后撤交替、治疗选择低生命比例友军，击杀后重新索敌。包含单体与多目标普攻/技能、前摇和命中复检、血条、阵亡和 BOSS 蓄力表现。索敌按间隔进行，目标有效时保持稳定；每帧移动与冷却独立更新。统一固定步长调度，空间哈希处理软碰撞，没有每单位定时器。

三种普通敌人（含后排优先的特殊射手）、一种精英、一只 BOSS。五波依次为 3、4、6、6、1 个敌人；第四波精英与普通敌军同时出现，第五波只有 BOSS。没有清场倒计时或强制跳波。友军波内阵亡保持死亡，下一次战斗开始按原布阵满血复活，全军阵亡立即失败。

击杀立即获得金币与经验；经验可在战斗中升级，强化选择队列在清场后集中展示，避免盖住正在交战的战场。连续升级不会丢失强化。每次升级最多两次金币刷新，选择效果加法叠加并有上限。清场按独立配置结算利息。胜败结算可重开或回主界面；也可通过「返回」确认离开当前局。

## Cocos Creator 3.8.8 运行步骤

1. 在 Dashboard 用 **3.8.8** 打开仓库目录；等待资源和脚本导入完成，不要新建空项目覆盖本目录。
2. 打开 `assets/scenes/MainMenu.scene`，点击编辑器浏览器预览。使用横屏窗口（推荐 1280×720 或手机横屏视口）。
3. 点击原有「开始挑战」，进入新增 Battle 场景。开局应为金币 100、阵容 0/3，开始战斗不可用。
4. 点击「转动命运 10 金」，等待九格动画，选择任意结果，再从三个方向选一个。拖动单位到左侧布阵区，点击「确认布阵」。建议首次先招募三位，兼顾前排和输出，避免纯治疗阵容。
5. 点击「开始战斗」。仅观察自主战斗；清场选择强化，补充阵容，继续五波。第四波有精英，第五波单独 BOSS。
6. 若使用构建面板，平台选 Web Mobile，方向 Landscape，勾选 **MainMenu 和 Battle 两个场景**，启动场景 MainMenu。或在 PowerShell 执行 `.\tools\build-demo.ps1`；安装路径不同时传 `-CreatorRoot`。
7. 构建位于 `build/demo-web`。执行 `npm run serve:demo` 后用浏览器打开 `http://127.0.0.1:4173`。请通过 HTTP 服务运行，避免直接双击 HTML 的文件协议限制。

验证环境：Node 22、本机 Creator 3.8.8 自带 TypeScript、Chrome。若 Creator 不在默认路径，运行检查前设置环境变量 `COCOS_CREATOR_ROOT`；浏览器测试可设置 `CHROME_PATH`。

```powershell
npm test
npm run typecheck
# 先构建、启动 serve:demo；浏览器测试依赖可通过 npm ci 安装
npm run test:browser
```

- 1280×720 横屏和 844×390 小尺寸横屏视觉检查通过，战场、HUD、九格转盘、转职选择完整显示，保留原主界面布局。
